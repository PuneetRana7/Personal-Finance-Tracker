# 💰 Personal Finance Tracker

A web-based finance management application designed to help users track income, monitor expenses, manage budgets, and visualize their financial activities through interactive dashboards.

## 🚀 Features

* **Income & Expense Tracking:** Record and manage financial transactions.
* **Budget Management:** Monitor spending and manage budgets effectively.
* **Interactive Dashboards:** Visualize financial data using charts and graphs.
* **Firebase Integration:** Support for authentication and cloud-based data management.
* **Responsive Design:** User-friendly interface built with React and Tailwind CSS.
* **Demo Mode:** Explore the application without requiring Firebase configuration.

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS
* **Backend & Authentication:** Firebase
* **Data Visualization:** Recharts
* **Build Tool:** Vite
* **Programming Language:** JavaScript
